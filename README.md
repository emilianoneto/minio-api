# API de Armazenamento de Objetos com Node.js e MinIO

Projeto desenvolvido para a disciplina de Análise e Desenvolvimento de Sistemas.

A aplicação implementa uma API REST em Node.js integrada ao MinIO,
utilizando a API compatível com Amazon S3.

## Tecnologias

- Node.js
- Express
- MinIO
- Docker
- Docker Compose
- AWS SDK for JavaScript
- Multer
- REST Client

## Requisitos

- Node.js
- npm
- Docker
- Docker Compose
- VS Code
- Extensão REST Client
